# ADR 0001: Transactional repository/workspace foundation

Status: accepted

M3.1 keeps the configured checkout as the live repository authority and creates
every task workspace generation under the configured state directory outside
that checkout. Generations bind the source filesystem identity and candidate
snapshot digest. Leases and runtime reservations carry monotonically
increasing fencing generations.

Task state uses `database/sql` with the CGO-free `modernc.org/sqlite` driver.
The database applies embedded numbered SQL, WAL, `synchronous=FULL`, and
foreign-key enforcement. Legacy JSON is read once, validated strictly, moved
to a `.migrated` name, and never dual-written.

Integration is a digest plan rather than a fake atomic filesystem transaction.
Each step is journaled before and after mutation using FD-relative operations;
restart recovery advances only steps already at their after-digest and
quarantines ambiguous states.

Rollback is generation discard/quarantine and reopening the prior state DB.
SQLite schema version is guarded by `PRAGMA user_version`; unsupported or
corrupt state fails closed.
