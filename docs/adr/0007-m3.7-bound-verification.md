# ADR 0007: Native repository intelligence and bound verification

Status: accepted

M3.7 detects Go, Node/package-manager, Rust, Nx, Turbo, and Bazel from native
manifests and emits typed commands. It does not implement a build graph or
replace the ecosystem's package/build tools. Affected/targeted plans are
explicit adapter arguments; full verification remains the fallback.

Every result binds repository identity, candidate snapshot, environment
generation, policy version, and plan digest. The verifier reads the snapshot
before and after execution and rejects a change as TOCTOU/stale rather than
returning a result that belongs to another candidate.
