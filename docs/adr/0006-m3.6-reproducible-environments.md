# ADR 0006: Reproducible environments and non-authoritative cache

Status: accepted

M3.6 derives an environment identity from repository/workspace identity,
platform, detected toolchain manifest, lockfile digest, policy version, and
runtime image. Toolchain detection reads native manifests; it does not build a
replacement package manager or build graph.

Cache artifacts carry a binding and content digest in a private manifest.
Reads verify path containment, regular-file type, size, digest, and exact
binding. A missing or deleted cache is a normal cold-cache path; a poisoned or
corrupt artifact is rejected. Package installation is delegated to a runtime
installer and only accepted when the compiled network policy is registry-only.
