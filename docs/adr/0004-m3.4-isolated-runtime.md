# ADR 0004: Isolated runtime backends

Status: accepted

M3.4 exposes one lifecycle contract with explicit states:
`CREATING → READY → RUNNING → STOPPING → STOPPED`, plus `FAILED` and
`QUARANTINED`. Runtime creation is bound to a workspace generation and live
lease fence; one runtime is admitted per generation.

The Apple `container` CLI is primary. It receives only the isolated generation
path as a mount, fixed CPU/memory limits, and `--network none` by default. The
adapter does not mount the live repository and does not construct host shell
commands. Lima is a fallback/test adapter and does not silently become the
primary runtime.

Persisted lifecycle records are replayed on startup. Active runtimes left by a
crash are stopped and deleted; failed cleanup is quarantined. Unsupported
network modes or missing adapters fail closed.
