# ADR 0002: Typed execution security

Status: accepted

M3.2 uses typed Go policy values and a compiler that emits narrow runtime
mount, network, credential-reference, and execution inputs. Capabilities are
deny-by-default. The compiler never emits a live-repository mount; runtime
work is bound to an isolated task workspace. Full network and host process
backends are rejected.

Repository enrollment binds repository and filesystem identities and issues a
trusted integration reference whose digest is retained by the authority.
Sessions bind principal and repository, and every request consumes a single-use
nonce before detailed authorization. Destructive and publication operations
require distinct one-time confirmation classes.

Credentials are represented only as scoped provider references; secret values
are not policy fields, task fields, audit fields, or log fields. Runtime
diagnostics are redacted before audit storage. Persistence of audit events and
credential broker integration are extended in M3.8 and the runtime phases.
