# ADR 0003: Supervised process abstraction

Status: accepted

M3.3 separates typed process supervision from runtime creation. A process
starts only from a compiled execution input supplied by a runtime backend; the
local starter is test-only and is not exposed as an MCP capability.

Output is chunked into a monotonic cursor stream. Memory is bounded; once the
bound is reached, chunks are written to a private durable JSONL spill file and
remain resumable by cursor. Cancellation and timeout terminate the entire
process group with escalation, and PTY is accepted only for explicitly
interactive specs. Environment input is allowlisted by shape and rejects
credential-bearing variable names.

Rollback is process-group cleanup and spill retention for diagnosis. PTY is an
optional adapter and can be unavailable on a restricted host without blocking
non-interactive execution.
