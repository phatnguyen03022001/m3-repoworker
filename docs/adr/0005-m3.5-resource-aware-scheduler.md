# ADR 0005: Resource-aware local scheduler

Status: accepted

M3.5 uses a local scheduler with a two-dimensional CPU/RAM admission budget.
Jobs are validated as a closed dependency DAG, selected from ready work with
weighted fair ordering, and constrained by global concurrency plus task and
runtime quotas. A bounded submission queue provides backpressure.

Each started job receives the shared cancellation context. A job failure
cancels siblings and the scheduler drains them before returning the first
failure. Optional host-pressure sampling reduces the available admission
budget; a fixed over-capacity job is unschedulable rather than partially
admitted. No Kubernetes/Nomad scheduler is involved.
